# Projekt 3 — GitHub Activity Analyzer

Nowe rzeczy z Pythona, które poznamy podczas budowy GitHub Activity Analyzera.

Plan (uzupełniany w miarę pisania kodu):

- `datetime` — praca z datami (commity per dzień/tydzień, parsowanie ISO 8601)
- `zip` — iterowanie po kilku listach naraz
- generatory / `yield` — paginacja API (lazy fetching dużych list)
- `pathlib.Path` — obsługa ścieżek (np. cache na dysku)
- `json` (moduł) — zapis/odczyt danych do pliku
